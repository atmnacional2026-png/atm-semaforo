Ver criterio del semáforo (5 niveles, en orden de prioridad)
🟢 Verde — Apta y en buen estado Apta para dictar cursos = Sí, etiqueta funcional "Inversión menor", activa y apta para circular, sin observaciones que la contradigan.
🟡 Amarillo — Apta, con alertas menores
  • Apta para cursos = Sí, pero está Inactiva
  • Etiqueta funcional "Puesta a punto"
  • Apta para circular = "Requiere revisión"
  • Especialidad declarada ≠ real
🟠 Naranja — Aptitud comprometida
  • Apta para cursos = "Requiere revisión"
  • Etiqueta funcional "Inversión sustantiva"
  • Estado de uso "En reparación"
  • No apta para circular (no se puede reubicar)
🔴 Rojo — No apta / crítica
  • Apta para dictar cursos = "No"
  • Etiqueta funcional "Desestimar continuidad"
  • Estado de uso "Cerrada"
⚪ Gris — Sin datos disponibles Faltan uno o más de los campos clave (apta para cursos, estado de uso o etiqueta funcional) para poder clasificarla.

Reglas aplicadas en cascada de mayor a menor gravedad: gana la primera que aplica. "Apta para dictar cursos" es la señal que más pesa: si es "Sí" y no hay excepciones, el ATM va a Verde. Esta clasificación ya viene calculada desde el origen (Office Script sobre el Excel); este panel solo la muestra.
